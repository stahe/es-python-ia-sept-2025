    Líneas :

    • 1: inicializar una variable. En Python, no se declara el tipo de las variables. Las variables tienen automáticamente el tipo del valor que se les asigna. Este tipo puede cambiar con el tiempo;

    • 3: resultado de la visualización ;
    • 4: muestra el tipo de variable nombre ;
    • 5: el nombre de la variable es del tipo class. Con Python 2.7 tendría el valor <tipo 'str'> ;

    • En [4-6], indique que su proyecto utilizará un entorno virtual. El entorno virtual creará una carpeta [.venv] en la raíz del proyecto. El proyecto sólo busca plugins en su propio entorno virtual [.venv] y no en otros lugares donde podría encontrar plugins con los mismos nombres pero posiblemente versiones diferentes que a veces son incompatibles entre sí;
