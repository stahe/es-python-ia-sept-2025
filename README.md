# Generar un script de Python con herramientas de IA

El objetivo de este proyecto es demostrar que, en ocasiones, la escritura de scripts algorítmicos complejos puede automatizarse gracias a las herramientas de Inteligencia Artificial (IA).

## Contexto del proyecto

Retomamos aquí un problema planteado inicialmente en 2020 en el curso «Python Flask 2020», disponible en Developpez.com.

Este curso se basaba en un **cálculo simplificado de impuestos para el año 2019**. En aquel momento, se desarrolló manualmente un script en Python para resolver este problema, que luego se adaptó en 18 versiones diferentes para, finalmente, trasladar este cálculo a una aplicación web MVC.

## Objetivo

El objetivo es demostrar que el script inicial de cálculo de impuestos puede, en septiembre de 2025, ser generado directamente por ciertas IA generativas, pero no por todas.

## Herramientas de IA probadas

Se han utilizado las siete herramientas siguientes para este experimento (septiembre de 2025):

* ChatGPT
* Grok
* Gemini
* MistralAI
* DeepSeek
* ClaudeAI
* Perplexity
